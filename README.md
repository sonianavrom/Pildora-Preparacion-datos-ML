# Píldora: Preparación de datos en Machine Learning.
¡Bienvenidos! Este repositorio contiene el material didáctico para la píldora: *Preparación de datos en Machine Learning*. 

Este espacio está diseñado para centralizar el acceso a la presentación teórica y a las actividades interactivas de la sesión.

## 📌 Contenido

* **Normalizando las variables**: El Escalado consiste en igualar el terreno para que todas las características numéricas compitan en igualdad de condiciones, sin importar sus unidades originales. Para ello aplicamos dos técnicas: la Normalización (Min-Max Scaling) y la Estandarización (Z-Score).
* **Codificando las variables**: La Codificación categórica asignan números enteros a las variables de texto. Para ello podemos aplicar tres técnicas de codificación: el Label Encoding (asigna número entero de forma aleatoria o secuencial), el Ordinal Encoding (cuando existe una jerarquía u orden real) y el One-Hot Encoding (crea una nueva columna binaria para cada categoría única).
* **Data Leakage o Fuga de Datos**: La Fuga de Datos se refiere a que el modelo puede entrenarse con información del futuro (del conjunto de test) que no debería conocer, contaminando la información.
